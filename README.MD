# BeamMP-SXMY_Plugin

BeamMP 服务器插件，基于 Lua 开发。

## 当前版本

**2.0.0.2608310348_Alpha**

## 目录结构

```
Resources/
├── Read.me         本说明文件
├── LICENSE         GPL-3.0 许可证文本
├── Client/         客户端资源
└── Server/
    └── SXMY_Plugin/  插件本体
        ├── main.lua        入口：配置生成 / 插件加载 / 配置查询 / 插件载入
        ├── config.toml     主配置（语言等）
        ├── Language/       语言文件（zh.json / en.json）
        └── lib/            功能模块（01.WelcomeMsg ~ 11.VoteKick）
```
